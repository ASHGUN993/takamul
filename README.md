# تكامل

منصة دروس مترابطة بين المواد (عرض تجريبي). موقع ثابت بلا خادم، يعمل على GitHub Pages.

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` | هيكل الصفحة والتصميم |
| `app.js` | الصفحات، والروابط، والبحث، والمساعد |
| `editor.js` | المحرّر (`#editor`) والوضع التجريبي (`#try`) |
| `content.js` | **كل المحتوى**: المواد والمواضيع والفروع والدروس والتجارب |
| `images/` | الصور |
| `videos/` | الفيديو المرفوع |
| `labs/` | التجارب، كل تجربة في مجلد |
| `vendor/` | مكتبة JSZip للتصدير |

## إضافة محتوى (أكثر من محرر)

1. صاحب المستودع يدعو كل محرر من **Settings ← Collaborators ← Add people**.
2. المحرر يفتح `الموقع/#editor`، ويعدّل الشجرة ويكتب الدروس ويرفع الصور والفيديو والتجارب. كل شيء يُحفظ تلقائيًا في متصفحه.
3. يضغط **«☁ نشر للجميع»**. في أول مرة يربط حسابه على GitHub برمز دخول (الرابط داخل النافذة يجهّز الصلاحية المطلوبة `public_repo`).
4. يظهر التعديل لكل الزوار خلال دقيقة أو دقيقتين.

إن نشر محرران في الوقت نفسه تُدمج تعديلاتهما تلقائيًا على مستوى الحقل. وإن عدّل الاثنان الحقل نفسه في الدرس نفسه يُنبَّه الثاني قبل النشر، وتُعتمد نسخته في هذا الموضع فقط.

بديل بلا GitHub: زر **«⤓ zip»** يُنزل المحتوى والملفات، فتفكّه داخل مجلد الموقع وترفعه.

## صيغة كتابة الدرس

| تكتب | يظهر |
|---|---|
| `## عنوان` | عنوان قسم (يظهر في «في هذا الدرس») |
| `**نص**` | نص غامق |
| `- عنصر` | قائمة |
| `[[ATP\|درس:chem-energy]]` | كلمة تفتح درسًا (بلون المادة إن كانت أخرى) |
| `[[فيديو\|https://youtube.com/…]]` | كلمة تفتح فيديو في نافذة |
| `[[مقالة\|https://…]]` | رابط خارجي |
| `![وصف](images/صورة.png)` | صورة بعرض الدرس |
| `![وصف](images/صورة.png){50% يمين}` | صورة بنصف العرض على اليمين والنص حولها (يمين / يسار / وسط) |
| `![وصف](videos/فيديو.mp4){75%}` | فيديو مرفوع، أو رابط يوتيوب مكان المسار |
| `::lab[معرّف_التجربة]` | تجربة داخل النص |

كل كلمة مرتبطة تُضاف تلقائيًا إلى فهرس المصطلحات، وإن ربطت درسًا بمادة أخرى ظهر في «مرتبط بمواد أخرى».
