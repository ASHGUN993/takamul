# تكامل

منصة دروس مترابطة بين المواد (عرض تجريبي). موقع ثابت بلا خادم، يعمل على GitHub Pages.

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` | هيكل الصفحة والتصميم |
| `app.js` | الصفحات، والروابط، والبحث، والمساعد |
| `editor.js` | المحرّر (`#editor`) والوضع التجريبي (`#try`) |
| `content.js` | **كل المحتوى**: المواد والمواضيع والفروع والدروس والتجارب |
| `images/` | الصور |
| `labs/` | التجارب، كل تجربة في مجلد |
| `vendor/` | مكتبة JSZip للتصدير |

## إضافة محتوى

1. افتح `الموقع/#editor`.
2. أضف أو عدّل من الشجرة، واكتب الدرس، وارفع الصور والتجارب. كل شيء يُحفظ تلقائيًا في متصفحك.
3. اضغط **«تصدير»**، فينزل ملف zip.
4. فكّه داخل مجلد الموقع (استبدل `content.js`)، ثم ارفع التغييرات إلى المستودع.

## صيغة كتابة الدرس

| تكتب | يظهر |
|---|---|
| `## عنوان` | عنوان قسم (يظهر في «في هذا الدرس») |
| `**نص**` | نص غامق |
| `- عنصر` | قائمة |
| `[[ATP\|درس:chem-energy]]` | كلمة تفتح درسًا (بلون المادة إن كانت أخرى) |
| `[[فيديو\|https://youtube.com/…]]` | كلمة تفتح فيديو في نافذة |
| `[[مقالة\|https://…]]` | رابط خارجي |
| `![وصف](images/صورة.png)` | صورة |
| `::lab[معرّف_التجربة]` | تجربة داخل النص |

كل كلمة مرتبطة تُضاف تلقائيًا إلى فهرس المصطلحات، وإن ربطت درسًا بمادة أخرى ظهر في «مرتبط بمواد أخرى».
